# ReAct

## 定义

让推理与行动交替、利用观察结果继续决策的方法。

## 例子

分析问题→调用工具→观察返回→调整行动。

## 边界

不是每次 function calling 都等同完整 ReAct；无需公开模型隐藏推理。
