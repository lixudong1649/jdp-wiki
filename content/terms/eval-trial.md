# 评测尝试

## 定义

智能体对一个评测任务进行的一次尝试。

## 解释

同一用例可以重复尝试，用于观察结果波动；整个批次的 Run 可包含多个 Trial。

## 例子

同一道问题执行三次，产生三次 Trial。

## 边界

Trial 与 Run 的命名因框架而异，不能直接视为同义词。
