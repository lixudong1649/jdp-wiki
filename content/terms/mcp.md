# MCP

## 定义

连接 AI 应用与外部工具、数据和工作流的开放协议。

## 解释

客户端与服务端按协议交换能力和消息；是否允许执行仍由应用的权限控制决定。

## 例子

Agent 通过 MCP 服务读取订单，只读权限由业务系统校验。

## 边界

协议不是工具商店，也不自动赋予业务权限。
