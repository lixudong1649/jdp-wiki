# Python 虚拟环境

## 定义

将项目使用的 Python 包环境与其他项目隔离的机制。

## 解释

venv 创建独立环境目录，安装的依赖通常只作用于该环境。

## 例子

项目 A 与 B 分别安装不同版本的同一 Python 包。

## 边界

依赖隔离不是安全沙箱，也不自动固定所有依赖版本。
