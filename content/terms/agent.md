# 智能体

## 定义

在目标与约束下感知信息、选择行动，并依据反馈继续执行的系统。

## 例子

根据订单状态自主选择查询或退款工具。

## 边界

LLM Agent 是其中一类；不能把所有 Agent 都限定为 LLM。
